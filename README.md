# PageVoice2

PageVoice2 是一个手机和 iPad 优先的英文拍照读书 PWA。它在浏览器本地识别英文书页，按句朗读并高亮当前句，还可以离线查询常见单词的中文释义。

## 功能

- 拍照或选择书页照片，在浏览器本地完成英文 OCR
- 校对识别文字，自动按英文句子分段
- 逐句朗读、高亮、跳句、单句重复与三档语速
- 点击单词查看中文释义、音标并听英文发音
- 使用 IndexedDB 保存阅读项目和进度
- 准备离线资源后，在无网络环境继续使用

## 隐私

书页照片和正文不会上传。OCR 完成后，项目只保存压缩缩略图和校对正文，不保存原始照片。清除浏览器的网站数据会同时删除本地项目。

## 本地运行

```bash
npm install
npm run dev
```

运行测试和生产构建：

```bash
npm test
npm run build
```

完整范围、优先级和验收条件见 `docs/PROJECT_PLAN.md`。
